Как импортировать

  1. Установите Meridian (macOS или Windows).
  2. При первом запуске приветственный тур предложит Import from Arc. Позже эта кнопка есть в настройках.
  3. На Mac разрешите запрос связки ключей. Так Meridian сможет прочитать ключ, которым Arc шифрует логины. На Windows сначала закройте Arc: пока он открыт, он блокирует файлы с логинами.

Ничего не покидает ваш компьютер, а сам Arc не меняется. Вы можете пользоваться им, пока он не перестанет работать 22 декабря.

Что переносится

  • Спейсы с цветами, иконками и названиями. Каждый профиль Arc становится профилем Meridian, поэтому рабочий спейс сохраняет свои куки и логины.
  • Закреплённые вкладки и папки в том же порядке. Сплит-вью и Easels из Arc переносятся как папки с их вкладками.
  • Избранное и открытые вкладки Today каждого спейса.
  • Логины: куки Arc копируются в соответствующие профили, поэтому на сайтах, где вы были залогинены, вход сохраняется.
  • Сохранённые пароли и карты, данные форм и адреса.
  • История, архив Arc и разрешения сайтов.
  • Boosts и правила Air Traffic Control.
  • Расширения из Chrome Web Store, которые заново устанавливаются в нужный профиль (на macOS).

Что не переносится

  • На Windows расширения Arc пока не переносятся. Установите их заново из Chrome Web Store.
  • Содержимое Easel (рисунки, текст, снимки) остаётся в Arc. Переносятся только ссылки, в виде папки.
  • Arc Sync и ваш аккаунт Arc: у Meridian пока нет своего аккаунта и синхронизации. Импортируйте данные на каждом компьютере.
Переезжаете из Google Chrome? File › Import from Chrome… переносит каждый профиль Chrome как спейс: закладки становятся закреплёнными вкладками и папками, а ещё приезжают открытые вкладки, входы на сайты, пароли, история и расширения. На Windows Chrome привязывает входы к себе, поэтому на сайтах придётся войти ещё раз. Пароли всё равно переносятся.
