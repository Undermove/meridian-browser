MCP-сервер в браузере

Любой MCP-клиент (Claude Code, Claude Desktop, Codex) может использовать 28 инструментов браузера: вкладки и спейсы, чтение страниц, клики и ввод текста, скриншоты, сплит-вью, Boosts, перевод и диалоги самих страниц. Чтобы подключить его, откройте Settings › AI и нажмите Connect рядом с Claude Code или Codex. Meridian покажет точную команду и выполнит её после вашего подтверждения.

Пока агент работает во вкладке, страница отрисовывается так, будто вы на неё смотрите, даже если Meridian свёрнут или закрыт другим окном. Ваша текущая вкладка при этом не меняется.

Уровни доступа

УровеньЧто могут агенты
Off (по умолчанию)Ничего. Управляющий сокет даже не открыт.
Read onlyВидеть вкладки и спейсы, читать страницы, делать скриншоты, искать в истории.
Ask before actingВсё, но каждый переход, клик, ввод текста или смена вкладки ждёт вашего подтверждения.
Full controlДействовать без вопросов, для агентов, которым вы доверяете.
  • Запуск JavaScript на страницах включается отдельно и по умолчанию выключен.
  • Клиенты подключаются через локальный сокет (на Windows через именованный канал) со случайным именем и токеном, новыми при каждом запуске. TCP-порта нет, поэтому сайты до него не достанут.
  • Текст страниц передаётся моделям с пометкой, что ему нельзя доверять, и моделям сказано никогда не выполнять инструкции со страниц.

Workbench: Claude Code рядом с localhost

Workbench (⇧⌘E, на Windows Ctrl+Shift+E) это вкладка браузера с деревом файлов, редактором Monaco, git (Source Control) и настоящими терминалами. В ней есть запуск в один клик для Claude Code, Codex, Gemini CLI, Copilot, OpenCode и других. Поставьте её в сплит-вью рядом со своим приложением на localhost. Агенты, запущенные там, получают инструменты браузера только на эту сессию, а ваши глобальные настройки не меняются.

  • Context Insights: каждая вкладка Claude Code показывает, насколько заполнен контекст. Один клик объясняет, куда ушли токены, и показывает ваши лимиты на 5 часов и на неделю.
  • Вкладки Claude Code возвращаются после перезапуска или обновления, с именами и режимом разрешений.
  • Mission Control (⇧⌘M): все агенты во всех спейсах, что каждый делает и кто ждёт вашего решения.
  • Когда агенту нужно решение, карточка появляется там, где вы сейчас находитесь, поэтому не нужно следить за терминалом.
  • Хранилище секретов отдаёт агентам API-ключи только как переменные окружения, а Meridian спрашивает, прежде чем Claude Code прочитает .env или файл с ключом.
  • Агенты в песочнице через Docker или OrbStack: агент видит только ваш проект.
