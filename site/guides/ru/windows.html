Что вы получаете на Windows

  • Спейсы со своим цветом, иконкой и профилем, поэтому рабочие и личные логины не смешиваются. Alt+1…9 или Ctrl+Alt+←/→ переключают между ними.
  • Закреплённые вкладки и папки, избранное и список Today, который архивируется сам.
  • Командная строка (Ctrl+T): открытые вкладки, история, архив и веб в одном списке.
  • Сплит-вью (Ctrl+Shift+=), Peek, Boosts и маленькое окно (Little window).
  • На базе Chromium: сайты, вход через Google, ключи доступа и расширения из Chrome Web Store работают как в Chrome.
  • Обновляется сам: проверяет обновления каждые 20 минут, показывает, что нового, и перезапускается с вашими вкладками.
  • Workbench и MCP-сервер для ИИ-агентов, которые пишут код.

Импорт из Arc на Windows

Сначала закройте Arc, затем выберите Import from Arc. Переносятся спейсы, закреплённые вкладки, папки, избранное, логины, пароли и история. Расширения Arc на Windows пока не переносятся, установите их заново из Chrome Web Store. Всё, что переносит импорт.

Установка

  1. Скачайте Meridian-win.exe (Windows 10 и 11, x64).
  2. Если SmartScreen пишет «Система Windows защитила ваш компьютер», нажмите Подробнее › Выполнить в любом случае. У Meridian пока нет платного сертификата Microsoft. У каждого релиза есть подписанные контрольные суммы (SHA256SUMS-win.txt), чтобы проверить загрузку.
Честно: сборку для Windows тестировали руками меньше, чем для Mac. Если что-то сломалось, пожалуйста, напишите нам. Windows на ARM не поддерживается.
