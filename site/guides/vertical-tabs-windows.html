If you only want vertical tabs: Microsoft Edge

Microsoft Edge has vertical tabs built in, so you may not need a new browser. Click the Search tabs icon in the top left of the window and choose Turn on Vertical Tabs, or press Ctrl+Shift+,.

If you want a sidebar to organize your day: Meridian

Meridian is a free, open-source browser built on Chromium, with the kind of sidebar Arc had:

  • Spaces with their own color, icon and profile, so work and personal logins stay apart. Alt+1…9 switches between them.
  • Pinned tabs and folders that stay put, plus Favorites.
  • A Today list for everything else, which archives itself.
  • A command bar on Ctrl+T that finds open tabs, history and the archive.
  • Split view on Ctrl+Shift+=, and Ctrl+S hides the sidebar when you want the whole screen.
  • Chrome Web Store extensions.

Coming from Arc? It imports your spaces, pinned tabs, folders and logins. Do that before Arc stops working on December 22.

Install on Windows

Download Meridian-win.exe (Windows 10 and 11, x64). Meridian isn't signed with a paid Microsoft certificate yet, so SmartScreen may warn you. The Windows guide walks through it.

Honest note: the Windows build has had less hands-on testing than the Mac one, and Windows on ARM isn't supported. If you need something well tested, stay with Edge.
