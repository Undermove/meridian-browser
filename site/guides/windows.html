What you get on Windows

  • Spaces with their own color, icon and profile, so work and personal logins stay apart. Alt+1…9 or Ctrl+Alt+←/→ switch between them.
  • Pinned tabs and folders, Favorites, and a Today list that archives itself.
  • Command bar (Ctrl+T): open tabs, history, the archive and the web in one list.
  • Split view (Ctrl+Shift+=), Peek, Boosts and the Little window.
  • Built on Chromium: sites, Google sign-in, passkeys and Chrome Web Store extensions work as in Chrome.
  • Updates itself: it checks every hour, shows what's new and restarts with your tabs.
  • The Workbench and the MCP server for AI coding agents.

Importing from Arc on Windows

Quit Arc first, then choose Import from Arc. Spaces, pinned tabs, folders, favorites, logins, passwords and history come over. Arc's extensions don't come over on Windows yet; install them again from the Chrome Web Store. Everything the import covers.

Install

  1. Download Meridian-win.exe (Windows 10 and 11, x64).
  2. If SmartScreen says "Windows protected your PC", click More info › Run anyway. Meridian isn't signed with a paid Microsoft certificate yet. Every release has signed checksums (SHA256SUMS-win.txt) to check the download.
Honest note: the Windows build has had less hands-on testing than the Mac one. If something breaks, please report it. Windows on ARM isn't supported.
