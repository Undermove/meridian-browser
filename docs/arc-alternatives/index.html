Arc alternatives, compared

Six browsers people move to from Arc, compared on facts. Every cell comes from the product's own site, docs or repository.

Checked on November 20, 2026. Products change fast: if a cell is out of date, please open an issue on GitHub.

We make Meridian, so read this with that in mind. We tried to be fair: no ratings, only facts each product states about itself. Where a product doesn't say, the cell says not stated.

Notes

  • Zen calls itself beta, and its builds are pre-release. Third-party scripts exist to move Arc data into it.
  • Crest is in early access. Its Windows availability isn't stated.
  • Ardia says "Mac only for now" but also offers Windows and Linux nightly builds, with an unsigned Windows installer.
  • Dia: The Browser Company's official route away from Arc. Arc's help center lists Arc features that Dia doesn't have: Air Traffic Control, Boosts, Easels, Little Arc, Peek, TypeTravel and Instant Links.
  • Meridian has Peek, Boosts, the Little window and Air Traffic Control, and a home for AI coding agents. The Windows build has had less testing than the Mac one, and there's no Linux or Intel Mac build.
