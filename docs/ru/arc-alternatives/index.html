Шесть браузеров, на которые переходят с Arc, в сравнении по фактам. Каждая ячейка взята с сайта, из документации или репозитория самого продукта.

Проверено 20 ноября 2026 года. Продукты быстро меняются: если ячейка устарела, пожалуйста, откройте issue на GitHub.

Meridian делаем мы, учитывайте это при чтении. Мы старались быть честными: никаких оценок, только факты, которые каждый продукт сообщает о себе. Если продукт об этом не говорит, в ячейке написано не указано.

Примечания

  • Zen называет себя бетой, его сборки предварительные. Для переноса данных Arc в него есть сторонние скрипты.
  • Crest в раннем доступе. Доступность на Windows не указана.
  • Ardia пишет «пока только Mac», но предлагает и ночные сборки для Windows и Linux, с неподписанным установщиком для Windows.
  • Dia: официальный путь The Browser Company для ухода с Arc. В справке Arc перечислены функции Arc, которых в Dia нет: Air Traffic Control, Boosts, Easels, Little Arc, Peek, TypeTravel и Instant Links.
  • Meridian: есть Peek, Boosts, маленькое окно и Air Traffic Control, а ещё рабочее место для ИИ-агентов. Сборку для Windows тестировали меньше, чем для Mac, сборок для Linux и Mac на Intel нет.
